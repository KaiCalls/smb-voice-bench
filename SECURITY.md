# Security

Do not put credentials, customer transcripts, real destinations or recordings in issues or public examples. This toolkit accepts untrusted JSON/media as data, rejects dynamic schemas/plugins/executables/remote artifacts, and renders imported strings through escaping or textContent.

Import is a local directory operation with bounded reads, no-follow path checks, hash verification and private atomic output. These controls reduce accidental evidence substitution; they cannot authenticate an external harness or defend a shared Python process against malicious code with filesystem access. Run third-party harnesses only in an environment you control.

For a suspected defect, prepare a minimal fictional reproduction and retain exact package/schema version. Coordinate privately with project maintainers before publishing exploit details. No report generated by this package is security, privacy, regulatory or production-readiness certification.
