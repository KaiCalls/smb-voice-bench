# Methods and limitations

The business state is independent of agent narration. SQLite enforces run ownership, unique booking per reservation, unique confirmation per booking, and run/tool/key idempotency. Requests commit before any injected delay; outcome receipts and successful business writes commit atomically. Unknown-write commits once, returns an unknown response, and requires status readback. The 256-bit capability is stored hashed and omitted from evidence. Closure rejects further access; audit access remains available. An audit-only reopen supports post-crash inspection without recovering or re-enabling a capability. A trusted harness shares a Python process with the sandbox; this is not isolation from malicious local code.

The deterministic references validate contracts and failure detection. They do not measure a provider, recognize consent generally, or exercise real audio. Their dispatch offsets are a synthetic clock; no observed model latency is inferred. Text correction establishes final intent only. A greeting interruption in audio mode needs planned overlap and runtime playback-stop evidence.

Optional `pcm-rms-v1` processing accepts 16kHz stereo signed 16-bit PCM WAV, caller left and assistant right. It uses 20ms windows, normalized RMS threshold 0.01 and caller-gap merging up to 1.2 seconds. Declared source-hash/channel/alignment lineage is mandatory; more than one frame (20ms) alignment error blocks precise timing. Audio format cannot establish who actually occupied each channel; external origin remains self-attested. Unsupported/mono audio remains preserved and yields unknown metrics. Imported originals are never resampled or edited.

Outcome gap is caller speech end to substantive assistant outcome onset, requiring cited reviewed outcome segments and aligned media. Filler is not an outcome. Interruption cutoff needs a runtime interruption/stop pair and positive overlapping speech; it checks PCM cessation near the stop. Unplanned overlap excludes only verified planned interruption intervals. Tool durations are independent dispatch spans, never relabeled audible latency. Legacy receipts without dispatch spans do not produce a tool duration. Missing alignment disables event-to-audio seeking.

Targets are internal product proposals: outcome gap ≤4000ms, interruption cutoff ≤500ms and unplanned overlap ≤100ms. The versioned phrase-list-v1 count of repeated generic fillers targets zero, stays labeled heuristic and never clears truthfulness. Human ratings target ≥4/5 for intelligibility, naturalness, entity accuracy and turn taking. Critical failures dominate averages. A report never combines these dimensions into a single quality percentage.

Distributions show count, median and maximum; p95 is absent below 20 valid observations. Cohorts join on scenario/suite/fault implementation/conditions/seed/execution mode/evidence origin/current evaluator and policy and the requested assessment scope. Candidate configuration is explicit. Multiple changed configuration fields are shown and labeled confounded; full snapshots remain in linked run reports. Different conditions or fixtures make rows incomparable; simultaneous software/adapter changes confound attribution. Small matching cohorts show observations, not reliability or statistical superiority. Distinct language, media corpus or audio conditions must stay separate.

Cost components are observed USD values with provenance. Unknown totals are null, never zero; partial runtime cost excludes missing synthesis or judgment components. None of these synthetic results demonstrates ROI, incremental revenue, compliance or production carrier behavior.
