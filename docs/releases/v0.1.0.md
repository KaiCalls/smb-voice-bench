# SMB voice bench v0.1.0

Open-source tests for AI receptionists that book, correct, and recover from tool failures.

This first offline engineering release includes seven frozen synthetic booking/recovery cases, an audited SQLite sandbox, good/bad reference controls, evidence import and evaluation, external capture export, evidence-bound human review, cohort comparisons and local HTML reports. The historical JavaScript fixture pack remains preserved separately in the source repository.

## Install the released wheel

Python 3.10+ on macOS or Linux/POSIX:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --require-hashes -r https://github.com/KaiCalls/smb-voice-bench/releases/download/v0.1.0/requirements.lock
python -m pip install --no-deps https://github.com/KaiCalls/smb-voice-bench/releases/download/v0.1.0/smb_voice_bench-0.1.0-py3-none-any.whl
smb-voice-bench doctor --json
smb-voice-bench demo --output ./demo-report
```

Open `demo-report/index.html` directly. The faulty control makes a second create decision after an unknown response; the corrected control reads the original booking status. A guard prevents another record, and the second decision still fails.

## Integrity and provenance

Release assets include the wheel, source archive, hash-locked runtime dependency list, `SHA256SUMS`, and `provenance.sigstore.json`. GitHub Actions signs build provenance with a short-lived Sigstore certificate identifying this repository’s release workflow. Verify downloaded package provenance with:

```sh
gh attestation verify smb_voice_bench-0.1.0-py3-none-any.whl --repo KaiCalls/smb-voice-bench --signer-workflow KaiCalls/smb-voice-bench/.github/workflows/release.yml
```

The signed workflow builds from the version tag, checks exact source/archive inventories, runs the 56 focused tests and exercises every installed CLI command before publication. Python 3.10/3.12 package CI, the seven good/bad controls, a 70-trace reference matrix and Chromium/Firefox viewer checks support this release.

## Scope

Bundled demonstrations are scripted text and tools; no recording, provider transport, customer data or private integration bridge is distributed. Imported external evidence remains self-attested. Listening and real-agent truthfulness require separate evidence-bound human reviews. Local confirmation records never establish message delivery, and synthetic passes do not establish production readiness.

The maintainer authorized this initial engineering publication after automated acceptance. An independent-person quickstart has not been recorded; no human quickstart or speech-review result is claimed. Distribution is through these GitHub release assets; no PyPI package upload is included.
